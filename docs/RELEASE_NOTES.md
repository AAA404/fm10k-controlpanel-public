# 更新说明

当前源码版本：`0.1.0-dev`，以仓库根目录的 `VERSION` 为准。以下描述软件行为，不表示某台设备已经安装或完成硬件验收。

## 控制面

- 配置预览、限时确认、回滚、控制恢复及持久事务结果。
- EPL 合口/拆分联动 VLAN，保留可恢复的拆分配置；端口详情支持缩放和按需诊断。
- 账户轮换保留替换后的会话，异步操作明确显示提交、回读及恢复状态。
- 协议、维护暂停、登录和确认窗口使用单调计时；系统时间由受限 NTP helper 管理。

## RDMA 与光学

- PCP/DSCP 静态 PFC、CNP 队列、IEEE DCBX、暂停诊断及默认关闭的 watchdog。
- PFC 生成映射与事务回滚、拥塞丢弃统计按本型号接口处理。
- RX 功率、二维接收眼图、取消和原生状态恢复；外部固件单独提供。
- Linux 软件 ECN 工具独立于 ASIC 数据面，保留真实能力限制。

## 源码分发

- 自有代码采用 Apache-2.0，第三方许可单独保留。
- 原厂平台配置、SDK 和参考固件由操作者本地提供，生产摘要校验保持启用。
- API 和诊断导出保留兼容字段，但不预置历史现场测试结果。
- Debian 包按显式文档白名单构建，公共 CI 使用人工平台样例。
