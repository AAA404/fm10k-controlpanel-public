# 更新说明

当前源码版本：`0.2.4`，以仓库根目录的 `VERSION` 为准。

## v0.2.4 实板在线升级恢复

- 修复 IGMP 运行态恢复对暂停时长和成员到期时间的错误上限。跨重启的端口暂停时长可能大于本次开机时长；旧规则会拒绝有效的持久记录，使 `l2d` 启动失败并触发 OTA 回退。
- 增加跨重启长暂停场景的原生进程恢复回归测试。
- 保留 v0.2.3 的在线升级按钮稳定性和统一样式修复。

## v0.2.3 在线升级界面修复

- 后台每 4 秒读取更新状态时保持按钮状态稳定；只有手动刷新和提交请求期间显示相应按钮的忙碌状态。
- 后台单次读取失败不再立即禁用安装操作；连续读取失败时提示连接问题，读取恢复后自动清除提示。
- “安装”使用主按钮样式，“检查更新”和“刷新状态”使用统一的次按钮样式。
- 浏览器回归覆盖后台读取挂起时的按钮可用性、操作样式、服务重启后的状态恢复及移动布局。

## v0.2.2 OTA 修复记录

- 修复进入维护模式时的配置修订号误判。configd 对面板报告的修订号比持久提交指针大 1；更新器现在使用相同的编号规则比较，仍会拒绝维护窗口中的真实并发配置提交。
- GitHub Release 连接在 DNS、TLS 或连接中断等临时网络错误后最多重试两次；HTTP 拒绝、权限与清单校验错误仍立即失败，不跳过资产摘要校验。
- 更新安装与 Release 传输测试覆盖上述两种情况。

在 Debian 13、6.12 内核的 A11 实板上，使用本地修补的旧版更新器完成了 v0.2.0 到 v0.2.1 的在线升级：新版原生服务、Web、受信任 HTTPS、配置回读及版本检查通过，配置摘要与升级前一致。一次硬件 mux 访问失败触发自动回退，旧版与配置均恢复；再次升级成功。该偶发硬件访问失败尚未定位，业务流量未验收。已安装的 v0.2.1 包本身仍含上述 OTA 问题，升级前需按维护方案修补更新器或使用离线迁移；本版将修复纳入正式制品。

## v0.2.1 修复记录

- 安装检查提前核验 PCI BAR0（至少 1 MiB）和 BAR4 已分配。缺少寄存器映射资源时，会在修改系统前停止安装。对于确认由 Linux 重新分配桥资源引起的板卡，安装文档记录了 `pci=realloc=off` 的诊断与重启核验方法；安装器不自动修改主机启动参数。
- 修复原生程序构建目录权限：以受控 umask 构建并清除组与其他用户的写权限，避免守护进程的启动保护拒绝执行。
- 修复 Debian 包在 `FM10K_PACKAGE_NO_START=1` 时仍启用服务的问题。首次安装仅在原生回读、Web 与受信任 HTTPS 健康检查通过后启用开机服务；失败时记录失败状态并清理已启用的单元。
- 修复包含 SDK 内部端口的 STP 快照枚举，内部端口不再占用 24 个用户端口预算，同时保留枚举步数上限。
- 修复 DHCP 管理地址在 nginx 启动后才出现时的开机绑定失败：生成的 nginx 配置会等待指定接口取得指定地址，HTTPS 健康检查覆盖实际管理入口。

这些修复的本地预览曾在 Debian 13、6.12 内核的 A11 实板安装并重启验证：PCI BAR、UIO、13 个原生服务、面板、nginx 和 HTTPS 恢复正常，配置回读为同步状态。正式 v0.2.1 制品仍应由部署者在自己的板卡上验证端口与流量；本次未做业务转发验收。

## v0.2.0 功能概览

## 安装与 GitHub 更新

- 完整 Release 压缩包、Debian Web 包、版本化清单和 SHA-256 文件；逐文件清单校验并限制解压内容。
- 全新 Debian 13 amd64 的只读准入与显式自动安装：系统、内核、板卡 PCI/VPD 修订、管理接口、SDK/平台文件、驱动/UIO 和旧栈冲突检查。
- 本地构建原生交换程序及 DKMS 驱动，生成关闭数据口的初始配置、HTTPS 与随机管理员凭据。
- GitHub 稳定版本检查、原生/Web 配套升级、维护期间写入锁定、配置与账户保留、失败回退及中断恢复。
- 公开仓库免令牌，私有仓库可使用 root 专属只读凭据；不会自动检查或安装，也不会在模拟模式访问板卡。
- 发布工作流通过公共 CI 和容器包安装后创建草稿供审核，不改变仓库可见性。

## 控制面

- 配置预览、限时确认、回滚、控制恢复及持久事务结果。
- EPL 合口/拆分联动 VLAN，保留可恢复的拆分配置；端口详情支持缩放和按需诊断。
- 账户轮换保留替换后的会话，异步操作明确显示提交、回读及恢复状态。
- 协议、维护暂停、登录和确认窗口使用单调计时；系统时间由受限 NTP helper 管理。

## RDMA 与光学

- PCP/DSCP 静态 PFC、CNP 队列、IEEE DCBX、暂停诊断及默认关闭的 watchdog。
- PFC 生成映射与事务回滚、拥塞丢弃统计按本型号接口处理。
- RX 功率、二维接收眼图、取消和原生状态恢复；外部固件单独提供。
- Linux 软件 ECN 工具独立于 ASIC 数据面，保留真实能力限制。

## 源码分发

- 自有代码采用 Apache-2.0，第三方许可单独保留。
- 原厂平台配置、SDK 和参考固件由操作者本地提供，生产摘要校验保持启用。
- API 和诊断导出保留兼容字段，但不预置历史现场测试结果。
- Debian 包按显式文档白名单构建，公共 CI 使用人工平台样例。
