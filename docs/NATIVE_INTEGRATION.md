# 原生控制面与板级集成

Web 以 `fm10k-web` 用户运行，通过 mgmtd 的受限 IPC 调用 configd。configd 的不可变快照、事务日志和活动指针是交换配置的持久化权威；switchd 独占 ASIC / SDK / I²C 访问。Web 不保存原生活动配置，也不提供任意 shell 或寄存器写入口。

## 接口与准入

| 接口 | 用途 |
|---|---|
| configd 19–23 | 快照、候选校验、提交、确认和回滚 |
| switchd 65 | 控制面保护和 CPU 出口整形回读 |
| switchd 120 / 125 | 固定槽位状态与计数器 / 完整 MAC 快照 |
| switchd 132 / 133 | 板级遥测缓存 / 受限手动 PWM |
| switchd 134 / 135 | 配置前镜像 / SDK generation 与恢复绑定，仅指定服务可用 |
| switchd 136 / 137 | 眼图任务采集、状态与取消，受硬件门禁限制 |
| 原生服务 200–202 | 配置协调中的端口暂停、恢复和状态查询 |

IPC 校验 Unix socket 对端身份与角色。原生启动核对实时 PCI/VPD/UIO、锁定 SDK、启动文件摘要和独占锁；保存的预检 JSON 不能代替实时检查。另一进程持有目标 ASIC 的 UIO/BAR 时拒绝接管。只有绑定和同步成功后才开放硬件写入，失败不会回退到模拟结果。

## 板卡映射与输入

B0 使用 `sil001-hw4-b0`，A11 使用 `sil001-hw5-a11`；二者的 SDK platform 名称均为 `sil001`，不应据此认定原厂参数可互换。原厂输入由操作者单独提供，校验与路径见 [构建说明](BUILD.md)。

OBT1 对应 EPL0/1/2，OBT2 对应 EPL5/6/7。每个 EPL 固定四个逻辑槽位，外部端口为 1–24；内部 PCIe 端口为 25/26，CPU 控制口为 27。物理 Lane 的调谐参数保留在其 EPL 的代表槽位上，合口时其他槽位保持禁用。逻辑映射不能替代 MPO/LC 物理线序核对。

生成器保留对应原厂 Lane 参数，过滤锁定 SDK 不支持的属性，生成固定端口、FCI 和混合缓冲布局。生产路径拒绝未知摘要和跨修订输入，测试样例不能作为设备配置使用。

## 配置与恢复

配置先完成模型、依赖和硬件计划校验，再由现有 SDK owner 串行执行。EPL 速率、风扇 LUT、VLAN、LAG、QoS 等操作保存各自前镜像，回读证明终态后才释放恢复状态。失败或回复丢失必须查询持久事务结果，不能以浏览器请求结束判定成功。

变更只协调其需要的对象；影响全芯片缓冲或全局 QoS 时，协调范围覆盖全部 EPL。扫描、协议暂停、SDK 访问与配置事务共享所有权规则。恢复不能通过全卡重启、驱动重载或第二个硬件操作者掩盖失败。

LACP 在协议参数或 SDK 实例变化时重新协商，拒绝旧实例的成员操作。IGMP 保持动态成员、失败恢复和进程重启接管状态；组播与 MAC 回读验证枚举完整性和 SDK 错误。CPU 保护针对控制面流量，不应对普通二层过境 ARP/ICMP 安装全端口丢弃规则。

确认窗口、协议周期及维护等待使用[单调计时](NATIVE_TIMERS.md)。硬件功能的跨进程恢复、真实重新协商和断电冷启动仍需按部署场景独立验收。

## 遥测与温控

SDK owner 分片采样温度、端口和 OBT 状态，读取 API 使用缓存而不直接访问硬件。每项读数具有采样时间及质量；缺失、过期或失败不得填成新的有效零值。

两个 OBT 使用独立物理 mux 与 12-bit 发射掩码；操作保留兄弟位并恢复 mux/page。LM96163 风扇路径保留 LUT、响应和回差设置，区分有效 TACH、估算值与故障；核心温度丢失、过热或无法证明恢复成功时按保护规则处理。光功率和眼图说明见 [OPTICS](OPTICS.md)。
