# 功能范围

此表描述源码提供的能力及限制。软件测试、配置回读和端口 Link Up 各自只能证明对应层面的行为，不代表具体部署已达到性能、无损或长期稳定性要求。

| 功能 | 提供的能力 | 边界 |
|---|---|---|
| 管理访问 | 管理员、会话、CSRF、HTTPS、账户轮换 | 首次创建账户；原生运行需要受限本机 IPC |
| 配置事务 | 预览、版本检查、提交、限时确认、回滚、备份 | 以 configd 的持久状态和最终回读为准 |
| 端口与 OBT | 24 固定槽位、六 EPL、10/25G 拆分和 40/100G 合口、12-bit TX 掩码 | 物理接线、模块和板卡修订需匹配；标称速率不代表吞吐 |
| 二层 | VLAN、MAC、LAG/LACP、RSTP、LLDP、IGMP | 故障切换、环路和跨设备互通需独立验收 |
| 流量策略 | 队列映射、调度、限速、风暴抑制和本地镜像 | 资源、硬件回读及与其他配置的依赖受校验约束 |
| RDMA / RoCE | 静态 PFC、PCP/DSCP、CNP 队列、IEEE DCBX | 单板、无环二层；不支持 RoCE over LAG |
| PFC watchdog | 暂停与队列观测、临时解除暂停、掩码恢复 | 默认关闭；可能有调度延迟、漏检和恢复丢包 |
| ECN | 独立 Linux 软件实验与外部标记节点 | FM10840 ASIC 本机拥塞 CE 标记不支持 |
| 温控 | 温度、PWM/RPM、12 点 LUT、限时手动控制和保护 | 无效/过期传感器值保持明确状态；TACH 需校准 |
| 光学 | RX 功率、Lane 状态、受限二维接收眼图 | TX 功率不支持；内部回环不评价外部光链路 |
| 系统时间 | systemd-timesyncd 状态、服务器配置与重试 | 需要可达 NTP；页面不提供任意系统命令或手工设时 |
| 三层 / OTA | 预留入口 | 写入或升级请求明确拒绝，未启用 |

协议、硬件和性能验收方法见 [硬件验收](HARDWARE_ACCEPTANCE.md)。RoCE 的具体语义见 [RoCE](ROCE.md)，光学限制见 [光学接口](OPTICS.md)。
