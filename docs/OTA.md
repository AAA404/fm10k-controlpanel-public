# GitHub 在线升级

完整 Release 安装启用对固定仓库 `AAA404/fm10k-controlpanel-public` 的稳定版本检查与原生程序/Web 配套更新。不会后台检查 GitHub 或自动安装；只有管理员的“检查更新”和已确认维护窗口的“安装”请求才触发操作。模拟模式不能执行安装。

## 操作与权限

1. 在“系统与维护 → GitHub 在线升级”检查版本。检查只读取 GitHub Release 元数据与清单。
2. 结束配置事务、限时确认、眼图与恢复操作，安排数据转发中断窗口；可先导出配置备份。
3. 核对目标版本，勾选允许重启交换服务，再提交安装。页面展示下载、构建、安装、验证、回退或失败状态。
4. Web 重启时页面会重新读取状态，不会自动重复安装。更新或恢复中，其他配置写入返回 HTTP 423。

登录和 CSRF 校验仍然适用于所有写请求。Web 账户不能运行 apt/dpkg、读取 GitHub 凭据或操作 SDK；它只通过 Unix socket 请求固定操作。系统服务验证连接进程身份，下载地址由服务器固定产生，API 不接受自定义仓库、URL、命令或令牌。

| 接口 | 行为 |
|---|---|
| `GET /api/v1/updates` | 已安装版本、兼容候选版本、持续任务状态；不访问 GitHub |
| `POST /api/v1/updates/check` | 空 JSON 对象；只接受已发布稳定 Release，排除草稿和预发布 |
| `POST /api/v1/updates/install` | `version`、`manifest_sha256`、`confirm_restart: true`；成功排队返回 202 |

候选检查有效期为一小时。降级、重复提交、旧摘要、清单变化、SDK 或接口不兼容均拒绝。检查失败会清除旧候选版本。

## 私有仓库

公开仓库不需要令牌。仓库仍为私有时，可由设备管理员在 `/etc/fm10k-controlpanel/github-token` 放置仅允许该仓库 **Contents: read** 的 fine-grained token，文件及父目录由 root 所有，文件权限必须为 `0600`。在设备端安全编辑该文件，不要把令牌放进 URL、命令行、Web 表单、源码或 Release 制品。

未配置凭据或无可见已发布 Release 时，检查明确报告不可访问，不会把它伪装为“已经是最新”。GitHub 下载只通过 HTTPS 和固定仓库 API；资产重定向到 GitHub 下载域名时不会携带 Authorization。

## 安装与回退

清单同时绑定源码提交、稳定版本、原生接口/配置版本、OS/板卡条件、SDK 清单摘要和制品 SHA-256。下载大小受限，解压拒绝路径穿越、符号链接、硬链接、特殊文件、重复项和超限内容。解压后再次核对全部源文件以及配套 Web 包。

升级在服务运行期间，用已安装且摘要匹配的本地 SDK 构建新原生程序并核对动态链接。SDK、内核驱动与原生依赖变更不走该流程。构建完成后重新检查实际 OS、VPD、驱动、UIO、管理接口和本地输入，再停止写入与服务。停止 configd 后核对持久配置指针，防止维护窗口边缘的并发 CLI 提交被覆盖。

检查点保存在 `/opt/fm10k-controlpanel/.rollback-…/`，包含旧原生程序、配置、Web 状态及旧 `.deb`；切换版本前同步写入文件和目录，并保存摘要。更新保留现有启动配置、账户、证书和业务配置；新版本必须通过全部原生服务存活、原生同步状态、配置一致性和 Web 版本健康检查。失败时自动恢复并验证原版本，恢复后的账户文件保留原有属主和权限。

持久事务记录位于 `/var/lib/fm10k-controlpanel-updates/transaction.json`。若更新进程或系统在切换中断，`fm10k-update-worker.service` 下次启动会先恢复检查点；已确认完成的事务按任务编号恢复状态，不重复安装。原生启动校验会阻止未恢复事务启动交换服务，只有当前恢复进程可临时允许健康检查所需的启动。下载/构建期间中断不自动重试。

若状态为“需要恢复”，维护锁与检查点会保留，避免继续写入。管理员应在维护环境检查 `journalctl -u fm10k-update-worker.service`、事务记录及检查点，修复空间/文件/服务问题后执行 `systemctl start fm10k-update-worker.service` 继续恢复。不要删除事务文件来强行解锁；回退包或检查点损坏时必须使用已验证的系统备份人工恢复。

这些检查点包含本地 SDK、设备配置与管理员数据，不得上传为公共制品。检查点恢复不等同于完整磁盘备份，也不能代替目标板卡的独立硬件验收。
